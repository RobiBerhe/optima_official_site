# 🌐 Technology Company Website Requirements (Next.js)

## 🏢 Project Overview

This project is to build a modern, responsive **technology company website** using **Next.js** with a clean **Teal & White** design theme.

The platform will showcase:

* Company profile
* Projects portfolio
* Services
* Partnerships
* Contact system with real email functionality

---

## 🎨 Design Requirements

### Color Scheme

* Primary Color: `#008080` (Teal)
* Secondary Color: `#FFFFFF` (White)
* Accent Colors: Light teal, gray shades

### UI/UX Guidelines

* Clean and professional layout
* Mobile-first responsive design
* Smooth animations and transitions
* Accessibility (ARIA labels, proper contrast)

---

## ⚙️ Technology Stack

* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Forms:** React Hook Form
* **Icons:** Heroicons / Lucide
* **Email Integration:** Nodemailer / Resend API
* **Deployment:** Vercel
